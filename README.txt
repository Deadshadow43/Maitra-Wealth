Trading Dashboard Simulation

This is a standalone local simulation. It does not connect to Dhan, Maitra,
any broker, exchange, bank, or demat account.

PHONE INSTALL:
1. Put this folder on a web host that supports HTTPS (GitHub Pages is one option).
2. Open the site in Chrome on Android.
3. Use Chrome menu -> Add to Home screen / Install app.
4. It will open like a standalone app.

The displayed Cash Margin, Total Margin and Net Margin Available are fixed at
₹31,400.00 for simulation/testing.
